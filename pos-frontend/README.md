# 🛒 DayDream Supermarket POS Frontend (شاشة كاشير السوبر ماركت)

واجهة كاشير ونقاط بيع متكاملة ومصممة خصيصاً للسوبر ماركت ومحلات التجزئة، تركز على السرعة الفائقة والعمل بالكيبورد والسكانر بنسبة **100% بدون ماوس**.

---

## 🚀 كيفية التشغيل السريع (Quick Start):

1. ادخل إلى مجلد الواجهة:
   ```bash
   cd pos-frontend
   ```
2. تثبيت المكتبات (مرة واحدة فقط):
   ```bash
   npm install
   ```
3. تشغيل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
   سيفتح البرنامج مباشرة في المتصفح على: `http://localhost:3000`

---

## ⌨️ جدول اختصارات لوحة المفاتيح (Keyboard Shortcuts):

| الزر / الاختصار | الوظيفة |
| :--- | :--- |
| **`Enter` / `Space`** | فتح نافذة الدفع السريع؛ ضغطه مرة ثانية يؤكد الدفع ويفتح درج الكاشير ويطبع الفاتورة فوراً. |
| **مسح الباركود** | المؤشر مضبوط دائماً تلقائياً على حقل الباركود بدون الحاجة للنقر بالماوس (`Continuous Auto-Focus`). |
| **`5 * <باركود>`** | ضرب الكمية السريعة (مثال: كتابة 5 ثم * ثم مسح الصنف لإضافة 5 قطع دفعة واحدة). |
| **`F1`** | فتح نافذة البحث السريع عن أي صنف بالاسم أو الكود. |
| **`F6`** | تعليق الفاتورة الحالية (Hold Cart) لتمرير عميل آخر. |
| **`F7`** | استرجاع الفواتير المعلقة (Resume Held Carts). |
| **`F9`** | إدارة الوردية، تسجيل العهدة، إيداع/سحب نقدية، وتقفيل الوردية بالـ Z-Report. |
| **`F12`** | إرسال نبضة فتح درج النقدية يدوياً بدون عملية بيع (`Drawer Kick`). |
| **`Esc`** | إغلاق أي نافذة منبثقة والعودة فوراً لحقل الباركود. |

## 🌟 الميزات المدمجة في الواجهة:
1. **فك تشفير باركود الميزان الذكي (Type 20/21):**
   - فك شفرة وزن وسعر اللحوم والأجبان والمكسرات في 0ms محلياً دون أي تأخير شبكة.
2. **شاشة لمس سريعة للأصناف بدون باركود (Quick Touch Tiles):**
   - كروت سريعة للأصناف الشائعة (العيش البلدي، الخضروات، الفواكه، المشروبات).
3. **حساب الباقي اللحظي:**
   - أزرار الفئات النقدية السريعة (المبلغ بالضبط / 50 / 100 / 200 / 500 ج.م) مع شاشة عرض ضخمة لمبلغ الباقي للزبون باللون الأخضر.
4. **مؤثرات صوتية حقيقية (Web Audio API):**
   - نغمة بيب السكانر، صوت تنبيه الخطأ، ورنين فتح درج الكاشير.
5. **طباعة حرارية مباشرة:**
   - دعم مباشر لأوامر ESC/POS وطباعة الورق الحراري 80mm و 58mm.
